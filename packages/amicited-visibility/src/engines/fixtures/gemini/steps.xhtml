Creating and activating a Python virtual environment on Linux is a straightforward process that isolates your project's dependencies from the global Python installation.

1
Install the venv package
Required for Ubuntu, Debian, and Linux Mint users
1.Install the venv package:Required for Ubuntu, Debian, and Linux Mint users.

Depending on your distribution, you may need to install the virtual environment package first. Open your terminal and run:

Bash 
sudo apt update && sudo apt install python3-venv

(Fedora/RHEL users can use sudo dnf install python3 as venv is usually included).

2
Navigate to your project directory
2.Navigate to your project directory:

Use the cd command to switch to the directory where you want to create your project:

Bash 
cd /path/to/your/project
3
Create the virtual environment
3.Create the virtual environment:

Run the following command to create a virtual environment named venv (you can replace venv with any folder name you prefer, though venv or .venv are standard conventions):

Bash 
python3 -m venv venv
4
Activate the virtual environment
4.Activate the virtual environment:

Run the activate script using the source command:

Bash 
source venv/bin/activate

Once activated, your terminal prompt will typically change to show the name of the environment in parentheses, like this: (venv) user@hostname:~$.

5
Verify the activation
5.Verify the activation:

To confirm that your terminal is using the virtual environment's Python interpreter rather than the system default, run:

Bash 
which python

This should output the path pointing to your virtual environment (e.g., /path/to/your/project/venv/bin/python).

When you are finished working and want to exit the virtual environment, simply run:

Bash 
deactivate
