# Fraunces font provenance

`fraunces-variable.ttf` is the normal Fraunces font derived from the
[Google Fonts source](https://github.com/google/fonts/tree/5e8a3ba899557829a76cfdac30fa512bda91d7ca/ofl/fraunces).
It retains the `wght` axis and the font's Latin, Latin Extended, and Vietnamese
glyph coverage. Its `opsz`, `SOFT`, and `WONK` axes are fixed at the source
Google API defaults (`14`, `0`, and `0`) to match the previous fixed-weight
request.

- Source file: [`Fraunces[SOFT,WONK,opsz,wght].ttf`](https://raw.githubusercontent.com/google/fonts/5e8a3ba899557829a76cfdac30fa512bda91d7ca/ofl/fraunces/Fraunces%5BSOFT%2CWONK%2Copsz%2Cwght%5D.ttf)
- Source commit: `5e8a3ba899557829a76cfdac30fa512bda91d7ca`
- Derived with: `fonttools varLib.instancer Fraunces[SOFT,WONK,opsz,wght].ttf opsz=14 SOFT=0 WONK=0`
- SHA-256: `24407bc98f27644c596d963e59b7e0e5608c143a389ee3ed7c71ca9f7d5f754c`
