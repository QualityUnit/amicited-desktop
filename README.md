# AmICited Desktop

Local-first AI agent workstation for marketers, built on top of [T3 Code](https://github.com/pingdotgg/t3code) (MIT). It drives the AI providers a marketer already pays for (Claude, Codex, Gemini and others), controls a built-in Agent Browser and the computer, ships a library of free marketing tools, and connects to [AmICited](https://amicited.com) over MCP.

Status: T3 Code imported with full upstream history (`upstream` remote = `pingdotgg/t3code`, merged weekly). The marketer layer is being built on top in `@amicited/*` packages. Upstream's README is kept at [docs/upstream/T3CODE-README.md](docs/upstream/T3CODE-README.md).
