# Open source licenses

AmICited Desktop includes third-party software and adapted assets. To read their license and attribution
notices:

- On web and desktop, open **Settings → About**, find **Open source licenses** under **Legal**,
  and select **View licenses**.
- On mobile, open **Settings → About AmICited Desktop → Open source licenses**.

The page lists the version when available, license identifier, and the parts of AmICited Desktop that include
or use the item. This also covers optional device tools that AmICited Desktop installs on demand instead of
bundling. Select a row to read the complete notice text. Use the search field to find a package,
version, license, or app component.

AmICited Desktop is based on [T3 Code](https://github.com/pingdotgg/t3code), which is available
under the MIT License. Its copyright notice is kept in the app's `LICENSE` file.
