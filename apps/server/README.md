# amicited

The AmICited Desktop CLI and server: a Node.js WebSocket server for the AmICited
Desktop app, and the `amicited` command that runs it.

```sh
amicited            # run AmICited here and open it in your browser
amicited --help     # list the commands
```

AmICited Desktop is based on [T3 Code](https://github.com/pingdotgg/t3code) (MIT).
Support: support@flowhunt.io · https://amicited.com
